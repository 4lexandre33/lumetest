# plugins

O Lume é uma plataforma de autoria. O manuscrito é a porta. Jogo e skills de canvas são secundários.

Antes de editar qualquer plugin: ler `CONTEXT.md` **dessa** pasta e [docs/ai/ROTEAMENTO.md](../../docs/ai/ROTEAMENTO.md).
Não criar plugin novo sem linha no MAPA e CONTEXT.md no mesmo passo.
Código novo não importa outro plugin — capability + evento.
